# DigiShot

> **Žádný displej. Čistá párty.**  
> Screenless retro digital camera designed for Gen Z & partygoers. Authentic retro flash and grain, photos revealed the next morning directly on your phone.

---

## 🚀 Features

- **Exact Hardware Design**: Dual-tone chassis, leatherette grip, 30mm f/2.4 glass lens, optical viewfinder, Xenon flash unit.
- **Interactive Before/After Slider**: Real-time slider comparing sterile smartphone photos with authentic DigiShot flash & film grain.
- **Phone Sync Experience**: Virtual USB-C transfer demo.
- **Multi-language Support**: 🇨🇿 Čeština, 🇬🇧 English, 🇩🇪 Deutsch.
- **Multi-currency**: CZK (Kč) and EUR (€) with dynamic price calculation.
- **Apple / Teenage Engineering Minimalist Header**: Frosted glass floating navigation with compact control cluster.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Framer Motion
- **Icons**: Lucide React + Official Vector Brand Assets
- **Deployment**: Vercel / Netlify
